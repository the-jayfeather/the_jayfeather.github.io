# 中秋博饼 · GitHub Pages 部署说明

本目录内容即为仓库内容：博饼游戏.html + ssets/（5 段瓷碗音效，必须一起上传）。

手机互联内置**三条通道**，在 设置 → 手机互联 中切换：
- **自动**：PeerJS 点对点直连（零配置，但依赖国外云信令，国内网络可能连不通）
- **国内云**：LeanCloud 国内云中转（国内稳定，推荐；需免费注册一次并填入 3 个参数）
- **局域网**：互联服务器.js（同一 Wi-Fi 最稳，但需电脑运行服务器）

---

## 部署步骤（网页上传，无需安装 git）

1. **创建仓库**：登录 github.com → 右上角 + → New repository
   - Repository name 填一个英文名，如 obing（不要用中文）
   - 可见性选 **Public**（免费托管必需）
   - 直接点 Create repository

2. **上传文件**：进入新仓库页面 → Add file → Upload files
   - 把本目录的 博饼游戏.html 和 ssets 文件夹（含 5 个 mp3）一起拖进上传区
   - 点 Commit changes 提交

3. **开启 Pages**：仓库页 → Settings → 左侧 Pages
   - Source 选 Deploy from a branch → Branch 选 main / /(root) → Save
   - 等待 1~2 分钟出现绿色提示

4. **得到网址**：形如
   `
   https://你的用户名.github.io/bobing/博饼游戏.html
   `
   （中文文件名在地址栏会自动编码，直接粘贴整条链接访问即可，无需手动改）

## 使用方法（电脑 + 手机）

1. 电脑打开上面网址 → 设置（右上角）→ 手机互联：显示 **4 位配对码**
2. 手机打开**同一个网址**（可让电脑扫码/发送链接）→ 设置中输入电脑的配对码 → 配对成功
3. 配对后摇动手机或点按「摇骰子」，电脑自动摇骰并播报，手机同步显示结果

## 三通道说明与选择

| 通道 | 稳定性 | 需要做的事 |
| --- | --- | --- |
| 自动（PeerJS） | 依赖国外云信令，国内常连不通 | 无需配置，直接用 |
| 国内云（LeanCloud） | 国内服务器中转，**推荐** | 免费注册 leancloud.cn → 创建应用 → 设置 → 应用凭证：把 AppID、AppKey、服务域名（形如 https://xxx.leancloud.cn）填入设置 → 保存并连接 |
| 局域网 | 同一 Wi-Fi 内最稳 | 电脑运行 
ode 互联服务器.js，手机访问 http://电脑IP:4567 |

## 注意事项

- **配对码**：电脑刷新页面或重启浏览器后会更换，需在手机上重新输入配对
- **国内云通道**：两端（电脑/手机）需使用同一套 AppID/AppKey；数据存于 LeanCloud 免费开发版，仅作消息中转
- **音效**：瓷碗音效文件在 ssets/，若未上传则该项无声；合成音效不依赖文件
- **备份**：本地 博饼工具\博饼游戏.html 才是日常编辑源文件，改好后替换到本目录再上传
