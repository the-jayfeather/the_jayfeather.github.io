# 中秋博饼 · GitHub Pages 部署说明

本目录内容即为仓库内容：`博饼游戏.html` + `assets/`（5 段瓷碗音效，必须一起上传）。

手机互联采用 PeerJS 点对点直连（无需任何本地服务器）：电脑生成 4 位配对码，
手机输入该码直连电脑；电脑与手机均通过公网打开本页即可，不再受局域网/防火墙限制。

---

## 部署步骤（网页上传，无需安装 git）

1. **创建仓库**：登录 github.com → 右上角 `+` → New repository
   - Repository name 填一个英文名，如 `bobing`（不要用中文）
   - 可见性选 **Public**（免费托管必需）
   - 直接点 Create repository

2. **上传文件**：进入新仓库页面 → `Add file` → `Upload files`
   - 把本目录的 `博饼游戏.html` 和 `assets` 文件夹（含 5 个 mp3）一起拖进上传区
   - 点 `Commit changes` 提交

3. **开启 Pages**：仓库页 → `Settings` → 左侧 `Pages`
   - Source 选 `Deploy from a branch` → Branch 选 `main` / `/(root)` → `Save`
   - 等待 1~2 分钟出现绿色提示

4. **得到网址**：形如
   ```
   https://你的用户名.github.io/bobing/博饼游戏.html
   ```
   （中文文件名在地址栏会自动编码，直接粘贴整条链接访问即可，无需手动改）

## 使用方法（电脑 + 手机）

1. 电脑打开上面网址 → 设置（右上角）→ 手机互联：自动识别为电脑，显示 **4 位配对码**
2. 手机打开**同一个网址**（可让电脑扫码/发送链接）→ 自动进入「骰子模式」→ 设置中输入电脑的配对码 → 配对成功
3. 配对后摇动手机或点按「摇骰子」，电脑自动摇骰并播报，手机同步显示结果

## 注意事项

- **配对码**：电脑刷新页面或重启浏览器后会更换，需在手机上重新输入配对
- **互联依赖 peerjs 云信令**（jsDelivr 引入的 PeerJS 公共信令服务器）：若配对一直失败，
  说明云信令不可达，可退回局域网模式：运行博饼工具目录下的 `node 互联服务器.js`，
  再照旧用局域网地址访问
- **音效**：瓷碗音效文件在 `assets/`，若未上传则该项无声；合成音效不依赖文件
- **备份**：本地 `博饼工具\博饼游戏.html` 才是日常编辑源文件，改好后替换到本目录再上传
