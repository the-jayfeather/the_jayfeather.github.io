# 中秋博饼 · GitHub Pages 部署说明

本目录内容即为仓库内容：博饼游戏.html + ssets/（5 段瓷碗音效，必须一起上传）。

手机互联内置**三条通道**，在 设置 → 手机互联 中切换：
- **自动**：PeerJS 点对点直连（零配置，但依赖国外云信令，国内网络可能连不通）
- **国内云**：LeanCloud 国内云中转（国内稳定，推荐；需免费注册一次并填入 3 个参数）
- **局域网**：互联服务器.js（同一 Wi-Fi 最稳，但需电脑运行服务器）

---

## 部署步骤（网页上传，无需安装 git）

1. **创建仓库**：登录 github.com → 右上角 + → New repository
   - Repository name 填一个英文名，如 obing（不要用中文）
   - 可见性选 **Public**（免费托管必需）
   - 直接点 Create repository

2. **上传文件**：进入新仓库页面 → Add file → Upload files
   - 把本目录的 博饼游戏.html 和 ssets 文件夹（含 5 个 mp3）一起拖进上传区
   - 点 Commit changes 提交

3. **开启 Pages**：仓库页 → Settings → 左侧 Pages
   - Source 选 Deploy from a branch → Branch 选 main / /(root) → Save
   - 等待 1~2 分钟出现绿色提示

4. **得到网址**：形如
   `
   https://你的用户名.github.io/bobing/博饼游戏.html
   `
   （中文文件名在地址栏会自动编码，直接粘贴整条链接访问即可，无需手动改）

## 使用方法（电脑 + 手机）

1. 电脑打开上面网址 → 设置（右上角）→ 手机互联：显示 **4 位配对码**
2. 手机打开**同一个网址**（可让电脑扫码/发送链接）→ 设置中把手机切换为「骰子模式」（手机遥控）
3. 配对方式二选一：
   - **自动发现（推荐）**：手机遥控面板会自动列出附近未配对的电脑（自动检测可用通道：国内云 + 局域网，列表会标注电脑所在通道），点对应配对码即发送请求，电脑弹窗点「同意」即配对成功；若手机当前通道与电脑不一致，会自动切换后再配对
   - **手动输入**：在手机设置中直接输入电脑的 4 位配对码配对
4. 配对后摇动手机或点按「摇骰子」，电脑自动摇骰并播报，手机同步显示结果
5. **多设备**：一台电脑可同时连接多台手机（每台手机配对后都会出现在电脑设置的「已连接设备」列表与各手机的「已连接设备」里）；任意一台手机摇动、或电脑自己摇骰，结果都会同步给所有已连接设备
6. **摇骰模式**（电脑设置 → 手机互联，仅电脑端显示此设置）：
   - **一起摇**（默认）：所有设备可随时摇骰，任何手机摇动都触发电脑摇骰
   - **分玩家设备**：在电脑「开局设置 → 玩家设备分配」中为玩家分配已连接手机（下拉选择，设备不可重复）；轮到该玩家时其手机摇动才触发电脑摇骰，其他设备会收到「还没轮到」提示；未分配设备的玩家由电脑端摇骰，电脑端始终可摇。手机端会只读显示「你被分配为：玩家 X」，无需自行选择

## 三通道说明与选择

| 通道 | 稳定性 | 需要做的事 | 自动发现 |
| --- | --- | --- | --- |
| 自动（PeerJS） | 依赖国外云信令，国内常连不通 | 无需配置，直接用 | 支持（手机自动检测可用通道并发现，配对时自动切换通道） |
| 国内云（LeanCloud） | 国内服务器中转，**推荐** | 免费注册 leancloud.cn → 创建应用 → 设置 → 应用凭证：把 AppID、AppKey、服务域名（形如 https://xxx.leancloud.cn）填入设置 → 保存并连接 | 支持（手机自动列出未配对电脑并请求配对） |
| 局域网 | 同一 Wi-Fi 内最稳 | 电脑运行 node 互联服务器.js，手机访问 http://电脑IP:4567 | 支持（手机自动列出未配对电脑并请求配对） |

## 注意事项

- **配对码**：电脑刷新页面或重启浏览器后会更换，需在手机上重新输入配对
- **国内云通道**：两端（电脑/手机）需使用同一套 AppID/AppKey；数据存于 LeanCloud 免费开发版，仅作消息中转
- **音效**：瓷碗音效文件在 ssets/，若未上传则该项无声；合成音效不依赖文件
- **备份**：本地 博饼工具\博饼游戏.html 才是日常编辑源文件，改好后替换到本目录再上传
