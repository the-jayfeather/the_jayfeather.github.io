播放顺序

先同类聚合，再按“涂蜡 → 含水 → 氧化 → 其他状态”的层级展开。

  1. 01方块种类铜块 → 切制铜块 → 雕纹铜块 → 切制铜台阶 → 切制铜楼梯 → 铜格栅 → 铜栏杆 → 铜链 → 铜灯笼 → 铜灯 → 铜门 → 铜活板门 → 铜箱子 → 铜傀儡像 → 避雷针 → 铜火把。
  2. 02涂蜡先展示全部未涂蜡组合，再展示全部涂蜡组合。
  3. 03含水每种可含水的方块，先全部干燥状态，再重复一遍“含水”状态。
  4. 04氧化未氧化 → 斑驳 → 锈蚀 → 氧化。
  5. 05其他状态楼梯：正置/倒置 → 左外/右外/左内/右内/直形 → 朝向；门、活板门、栏杆等按各自状态优先级展开。

HOW TO PLAY

铜方块，一块一块闪

这是一个向 Minecraft 铜系列方块致敬的小播放器。默认暂停在第一项，点“开始快闪”即可按顺序自动播放。

  • 方块库：选择要播放的方块种类；“完整”模式展开全部状态组合，“精简”模式每类只保留 8 个氧化/涂蜡变种。
  • 状态名称：所有状态会用“的”串联在方块名前面，例如“倒置的向右外角的斑驳的铜楼梯”。
  • 朗读：开关默认关闭。打开后会调用浏览器自带语音，并且一个方块会停留到朗读结束才切换。控制栏的“音色”下拉框可以切换自动、Edge 在线自然语音和本地语音；旁边的小下拉框可单独选择朗读语速（自动 / 0.8×–1.5×），两项选择都会保存在本机。
  • 预加载：当前方块开始朗读时，会把下一个方块的语音提前加入朗读队列，减少两项之间的等待与合成延迟。
  • 自定义：添加自己的铜方块条目；它会追加在播放列表末尾，并保存在当前浏览器。
  • 顺序：先未涂蜡后涂蜡；可含水方块先干燥后含水；每种内先按未氧化 → 斑驳 → 锈蚀 → 氧化，再按朝向、半砖、开关等状态排序。
关于“直到朗读完毕”

开启朗读后，切页计时器会暂停，由语音合成的 end 事件推进；如果浏览器没有可用语音或朗读失败，会自动回退到“停留时长”。

在 Edge 中会优先选择 Microsoft 晓晓 Online (Natural) 等自然语音；若自动改用本地语音，语速会加快到约 1.24×。在线自然语音不可用时会自动回退到本地语音。
